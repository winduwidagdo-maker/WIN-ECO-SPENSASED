# WIN-ECO-SPENSASED
ECO SPENSASED adalah program Adiwiyata khas SMP Negeri 1 Sedati yang menanamkan budaya peduli lingkungan melalui tujuh misi: pemilahan sampah, pengomposan, kota hijau, kalkulasi sampah, literasi, pemecahan masalah, dan aksi nyata. Membentuk siswa berkarakter Pahlawan Bumi yang bertanggung jawab, kreatif, dan berkelanjutan.
